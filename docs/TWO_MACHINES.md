# Партия на двух машинах: главный ПК + офисный ноутбук

18.11.2026. Ноутбук (Intel Core Ultra 5 125H, Arc, Quick Sync) помогает главному ПК (RTX 3070) собирать одну партию.
Материалы на ноутбук не копируются: он запускает те же сборщики прямо из общей папки `\\192.168.11.39\farm`
(`\\WIN-22OHGHD63MT\farm`), поэтому код у машин один.

## Как это устроено

- **Общая папка.** `farm` на главном ПК открыта в сети (SMB, «Изменение» для `WIN-22OHGHD63MT\user`, сеть «Частная»).
  Пути в сборщиках считаются от папки скрипта: на ноутбуке исходники и выдача берутся прямо из общей папки.
- **Заявки** (`core/farm_node.Claims`). Ролик собирает та машина, что первой создала `<ролик>.claim`. Файл создаётся
  с `O_EXCL`, поэтому два компьютера один ролик не возьмут. Пока ролик собирается, заявка обновляется раз в 30 с.
  - Готовый ролик → `<ролик>.done`.
  - Брак или ошибка → заявка снимается, ролик берёт любая машина.
  - Заявку упавшего процесса своя машина забирает сразу. Чужую забирают через 10 мин тишины (`FARM_CLAIM_STALE`).
  - Папка заявок: `output/_work/<сборщик>/claims/<партия>`.
- **Общий банк уникальности.** Отпечатки принятых роликов лежат в `acc/*.npy` (пишутся атомарно). Сверка
  «готовый ролик ↔ банк → запись отпечатка» идёт под общим замком `acc/.bank.lock` (`shared_lock`: блокировка байта
  файла, SMB держит её для всех машин). Поэтому две машины не примут два похожих ролика одновременно.
- **Временные файлы ноутбука** лежат на его диске: `%LOCALAPPDATA%\farm_work` (`FARM_LOCAL_WORK`, `local_dir`).
  В общую папку уходят только готовый mp4, отпечаток и план.
- **Перевод под Intel** (`core/hw.py`, включается при импорте `core.gpu_ffmpeg`). На ПК с NVIDIA ничего не меняет.
  Без NVIDIA:
  - распаковка `h264_cuvid` с `-crop/-resize` → процессор + `crop,scale` первым фильтром;
  - `-hwaccel cuda` убирается;
  - `overlay_cuda/scale_cuda/hwupload_cuda` → обычные фильтры;
  - NVENC → Quick Sync (`h264_qsv`, `-cq N` → `-global_quality N`), нет Quick Sync → libx264;
  - `-filter_complex_script` → `-/filter_complex` (ffmpeg 9 на ноутбуке);
  - torch: cuda → xpu (Arc, проверяется roi_align/half при старте) → процессор.
- **Замки видеокарты** (`core/gpu_slots`) у каждой машины свои. На ноутбуке 4 сборки сразу, видеопамять не меряется.
- **Дашборд** http://localhost:8767 показывает и ноутбук: файл `_qa_progress/<МАШИНА>-<pid>.json` обновляется раз в 20 с.
  Лог ноутбука дублируется в `output/_work/_node_logs/<МАШИНА>_<скрипт>_<pid>.log`.

## Запуск

На главном ПК, как обычно:

    python build_inspoy_moveon_v2.py --run 2m --yt 40 --jobs 6

На ноутбуке — та же партия, теми же ключами:

    \\192.168.11.39\farm\two_machines_laptop.cmd build_inspoy_moveon_v2.py --run 2m --yt 40 --jobs 6

Машины можно запускать в любом порядке и в любой момент. Кто первым закончит свои ролики, ждёт соседа и забирает
брошенное. В конце каждая пишет «всего готово (все машины): N из M».

Подключены: `build_inspoy_moveon_v2.py` (партия и `--run`) и `build_matryoshka.py --redo` (пересборка папок).
Другой сборщик подключается так же:
- `Claims.take/done/drop` вокруг одного ролика;
- `shared_lock` вокруг «сверка с банком + запись отпечатка»;
- `local_dir` для промежуточных файлов;
- `Progress` для дашборда.

## Проверка на одном ПК (без ноутбука)

Второй процесс изображает ноутбук:

    set FARM_HOST=SIMLAPTOP& set FARM_REMOTE=1& set FARM_HW=intel& set FARM_TORCH=cpu& python build_inspoy_moveon_v2.py --run 2mtest --yt 10 --jobs 2

`FARM_HW=intel` — Quick Sync встроенной графики i7-12700, `cpu` — libx264.

## Помощник на ноутбуке (запустить один раз — дальше всё с ПК)

На ноутбуке, один раз (`--autostart` — ещё и запуск при входе в Windows через «Автозагрузку»):

    start "farm worker" cmd /k "\192.168.11.39\farm\two_machines_laptop.cmd farm_worker.py --autostart"

`farm_worker.py`:
- шлёт загрузку ноутбука на дашборд (`_node_load/<МАШИНА>.json`);
- берёт задания из `output/_work/_farm_jobs/` и запускает только `.py` из корня папки farm;
- пишет лог в `_node_logs/<МАШИНА>_<id>_<копия>.log`;
- перезапускается сам, если в общей папке появилась новая версия.

Задания ставятся с главного ПК:

    python farm_jobs.py run build_inspoy_moveon_v2.py --run 2m --yt 40 --jobs 6      # всем помощникам
    python farm_jobs.py run --hosts LAPTOP-X --copies 2 build_matryoshka.py --redo output/папка
    python farm_jobs.py ls                                                           # кто на связи, что идёт
    python farm_jobs.py stop <id> | all

`--copies 2` — две копии сборщика на ноутбуке, если одна не загружает его до предела (копии берут ролики из одного
списка заявок).

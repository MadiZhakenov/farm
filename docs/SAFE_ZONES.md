# Безопасные зоны для текста (TikTok · Instagram · YouTube Shorts)

**Обязательно для всех проектов:** карусели, рилсы, сторис, фото-посты, любой текст поверх кадра.
Текст (и всё, что должно читаться: лицо, экран игры, логотип) должен целиком лежать внутри зелёной рамки ниже.
Если текст туда не помещается мимо лица/главного объекта — переносим строку, уменьшаем кегль или пропускаем
эту пару «кадр + текст», но **не** ставим текст под интерфейс.

Константы и проверка в коде: [`core/safe_zones.py`](../core/safe_zones.py).

## Рамки по форматам

| Формат | Холст | Текст по X | Текст по Y | Что закрывает интерфейс |
|---|---|---|---|---|
| Карусель **3:4** | 1080×1440 | 180–900 (ширина ≤ 720) | 6–78 % (86–1123 px) | справа кнопки TikTok — правые ~14 % (x ≥ 926) от 46 % высоты до низа; снизу подпись/точки при длинном описании, в полноэкранной Инсте и в Shorts — нижние ~20 %; сверху справа счётчик «1/6» Инсты (x ≥ 86 %, y ≤ 7 %) |
| Карусель **4:5** | 1080×1350 | 180–900 (ширина ≤ 720) | 6–78 % (81–1053 px) | то же, что у 3:4 (фото так же встаёт под вкладки во всю ширину) |
| Рилс / видео / фото **9:16** | 1080×1920 | 140–940 (ширина ≤ 800) | 200–1540 px | сверху вкладки TikTok / шапка Reels (~200 px); снизу ник + подпись + музыка (TikTok ~334, Shorts 300–360 px) → нижние 380 px; справа колонка лайк/коммент/шер (~140 px) от ~45 % высоты |

Другой размер холста — те же доли (рамка масштабируется пропорционально).

## Как проверять перед сборкой партии

1. Тест 2–3 штук, наложить зоны: `core.safe_zones.draw_overlay(img)` — красное = интерфейс, зелёная рамка = текст.
2. Для оверлеев с прозрачностью (PNG с текстом) — `python core/safe_zones.py <png...>`: печатает нарушения.
3. Проверять **все** раскладки (у каждого клипа/кадра своя), а не один кадр.
4. Лица и главный объект — отдельная проверка (см. `build_1275_reels.py`: face-aware раскладка + `fits()`).

## Откуда цифры

- Официальных безопасных зон для обычных (не рекламных) постов ни TikTok, ни Meta, ни YouTube не публикуют.
- **3:4 / 4:5 в TikTok** — замер по пикселям официального макета фото-режима из TikTok Newsroom
  (фото 3:4 во всю ширину сразу под вкладками; ник/подпись/музыка/точки под фото; колонка
  аватар/лайк/коммент/сохранить накрывает правые ~14 % фото начиная с ~46 % высоты).
  Kapwing: у каруселей фото не обрезается, фон чёрный. Длинная подпись сжимает/обрезает фото.
- **9:16** — сводка гайдов и открытых оверлеев (organic-замер TikTok: верх ~200, низ ~334, справа ~140 px;
  Shorts: низ 300–360, справа ~96, верх ~120). Берём самое строгое из реальных значений.
- Повод: в 1248 текст стоял на 80 % высоты и был до 864 px шириной — его задевали элементы приложений.

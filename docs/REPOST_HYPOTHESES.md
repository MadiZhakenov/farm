# Журнал гипотез: перезалив чужих товарных роликов («амазоновские» видео)

Живой документ. После каждого раунда записываем: что сделали, где лежат файлы, как заливали, какой результат и какой вывод.
Ничего не удаляем. Неудачные гипотезы тоже остаются, чтобы их не повторять.

Цель: чужие вирусные UGC-ролики с товарами («Amazon finds», подарки) должны набирать просмотры на наших аккаунтах.
Призыв в ролике ведёт в комментарии и личку за ссылкой.

## Что общее у всех 250 прошлых заливок (нельзя повторять вслепую)

1. **В кадре 100 % чужой картинки.** Платформа сравнивает ролики по смыслу кадра, а не по пикселям, поэтому эти ролики, скорее всего, уже есть у неё в базе как оригиналы чужих авторов.
2. **На всех стояла плашка `comment "UNLOCK" … secret link 🔗`**, включая контроль h13. Это прямой призыв комментировать ради ссылки (engagement bait) плюс «секретная ссылка». Такое само по себе может резать показы. Как этот фактор влияет отдельно, ни разу не проверяли.
3. **Условия заливки нигде не записаны:** сколько аккаунтов, прогреты ли они, гео, сколько роликов в день, описание, звук. 230 почти одинаковых копий на одних и тех же аккаунтах сами по себе похожи на спам.
4. **Не было положительного контроля.** Ни разу не залили на тот же аккаунт заведомо свой оригинальный ролик, чтобы проверить, что аккаунт вообще получает показы.
5. **Музыка из нашей библиотеки, не трендовая.**
